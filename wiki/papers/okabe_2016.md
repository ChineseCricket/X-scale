# Okabe & Smith (2016)

## One-line Summary
**本项目 LoCuSS 样本 M500 的直接来源。** 50 个 X 光亮团 (0.15≤z≤0.3) 的 Subaru 弱透镜质量测量。

## Sample
50 个 X 光亮团 (0.15 ≤ z ≤ 0.3)，Subaru/Suprime-Cam 统一高质量观测。LoCuSS (Local Cluster Substructure Survey)。

## Key Results
- **M500 (individual)** — 本项目使用的 LoCuSS M500 来源
- M500 范围: ~$3\times10^{14}$–$1.5\times10^{15} h^{-1} M_\odot$
- 统一的观测和数据处理

## Methods
- Instrument: Subaru/Suprime-Cam
- Weak lensing shear analysis
- NFW profile fitting
- 注意: M500 原始单位为 $h^{-1} M_\odot$，本项目已转换为 $M_\odot$ (h=0.7)
